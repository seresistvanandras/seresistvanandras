# István András Seres — academic website

A clean, static GitHub Pages site with a black/orange academic design.

## Publish on GitHub Pages

1. Create a repository named `<your-github-username>.github.io`.
2. Upload the **contents of this folder** to the repository root.
3. In GitHub: Settings → Pages → Deploy from a branch → `main` / root.
4. Wait for the Pages deployment to finish.

No build step is required. `.nojekyll` is included.

## Content sources used

- Existing ELTE website and CV
- Google Scholar / DBLP links
- Public conference and seminar pages
- User-selected YouTube talks
